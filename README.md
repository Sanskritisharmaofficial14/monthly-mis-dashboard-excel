# 📊 Monthly MIS Dashboard – Excel

## 📌 Project Overview

This project is an Excel-based Monthly MIS Dashboard designed to analyze
business performance and present key management information in a simple
and interactive format.

The dashboard helps track monthly revenue, orders, expenses, targets,
actual performance, and overall business KPIs.

---

## 🎯 Objective

The main objective of this project is to:

- Analyze monthly business performance
- Compare Target vs Actual performance
- Track revenue and expenses
- Calculate achievement and growth percentages
- Identify high and low performing departments
- Present important KPIs through an interactive dashboard

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- XLOOKUP
- SUMIFS
- COUNTIFS
- IF
- IFERROR
- Date Functions

---

## 📁 Dataset

The dataset contains the following fields:

| Column | Description |
|---|---|
| Month | Business month |
| Department | Department name |
| Employee | Employee name |
| Target | Monthly target |
| Actual | Actual achievement |
| Revenue | Revenue generated |
| Orders | Number of orders |
| Expenses | Business expenses |
| Customers | Number of customers |
